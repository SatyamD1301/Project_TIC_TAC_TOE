🎮 Tic Tac Toe Game
A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.
This project demonstrates core concepts of front-end development, including DOM manipulation, event handling, and basic game logic.

🚀 Features
1.> 🎯 Two-player game (Player X vs Player O)

2.> 🧠 Real-time game logic with win and draw detection

3.> 🔄 Restart game functionality

4.> 📱 Responsive and user-friendly UI

5.> ⚡ Fast and lightweight (no external libraries)

🛠️ Technologies Used

--> HTML – Structure of the game

--> CSS – Styling and layout

--> JavaScript – Game logic and interactivity

📂 Project Structure

TIC_TAC_TOE/
│
├── index.html        # Main HTML file
├── style.css         # Styling for the game
├── script.js         # Game logic
└── README.md         # Project documentation


🧩 Game Rules
=> Player X starts the game.

=> Players take turns marking empty cells.

=> The first player to align 3 symbols (row, column, or diagonal) wins.

=> If all cells are filled without a winner, the game results in a draw.
